# 🧹 URL Cleaner – Strip Tracking Junk from Links
# 🧹 URL 清理器 – 去除链接中的跟踪垃圾

**English** | **中文**

Paste a messy link. Get a clean one. Zero data sent anywhere. | 粘贴一个混乱的链接。获得干净的链接。数据不会发送到任何地方。

## ✨ What It Does | 功能说明

URL Cleaner removes tracking parameters from URLs while preserving the essential parts: | URL 清理器会移除 URL 中的跟踪参数，同时保留必要部分：

- ✅ Keeps: protocol, domain, path, port, hash | ✅ 保留：协议、域名、路径、端口、哈希值
- ✅ Preserves: non-tracking query parameters (e.g., `?id=123`) | ✅ 保留：非跟踪查询参数（例如：`?id=123`）
- ❌ Removes: `utm_*`, `fbclid`, `gclid`, `msclkid`, `from`, `spm`, `_branch_match_id`, `wechatShare`, and any parameter containing "track", "click", or "ref" | ❌ 移除：`utm_*`、`fbclid`、`gclid`、`msclkid`、`from`、`spm`、`_branch_match_id`、`wechatShare`，以及任何包含 "track"、"click" 或 "ref" 的参数

## 🔒 Privacy First | 隐私优先

**Runs entirely in your browser. No server. No logging. No data leaves your device.** | **完全在浏览器中运行。无服务器。无日志记录。数据不会离开您的设备。**

## 🚀 How to Deploy | 如何部署

Just upload `index.html` to: | 只需上传 `index.html` 到：

- **GitHub Pages**: Push to a repo, enable Pages in settings | **GitHub Pages**：推送到仓库，在设置中启用 Pages
- **Cloudflare Pages**: Drag and drop `index.html` | **Cloudflare Pages**：拖放 `index.html`
- **Any static hosting**: It's a single file, works anywhere! | **任何静态托管**：这是单个文件，可在任何地方使用！

## 📝 Example | 示例

**Before:** | **清理前：**
```
https://example.com/product?id=123&utm_source=google&utm_medium=cpc&fbclid=abc123&spm=xyz
```

**After:** | **清理后：**
```
https://example.com/product?id=123
```
